# Retrieve mode

## Goal

Answer from the knowledge base with inspectable provenance and appropriate uncertainty.

## Retrieval ladder

1. Resolve exact IDs, paths, titles, aliases, and properties.
2. Search Markdown and extracted text lexically.
3. Follow maps, links, backlinks, projects, and source relationships.
4. Use semantic retrieval only to expand candidates, never as final evidence.
5. Open the relevant source note and, for consequential claims, verify the preserved original.

State whether an answer comes from a source, user-stated preference, prior decision, or inference. Cite local note/source paths. When sources conflict, define the exact disagreement, test scope/time/terminology differences, and report real, apparent, or unresolved conflict.

Do not modify knowledge merely because retrieval exposed a likely correction. Propose the correction and route it through curate mode.
