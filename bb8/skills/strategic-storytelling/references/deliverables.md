# Strategic Storytelling Deliverables

Use only the sections needed for the request. A full audit can use the complete structure below.

## 1. Strategic thesis

State the governing insight in one short paragraph:

> We are trying to advance **[purpose]** for **[beneficiary]**. The strategy depends on delivering **[priority benefits]** through **[defining experience]**. The current feature set is **[aligned / partially aligned / weakly aligned]** because **[decisive reason]**.

## 3. Top-down narrative

Use a chain such as:

> To advance **[purpose]**, **[customers]** must receive **[benefits]**. They receive those benefits when **[experience]**. We should therefore enable **[features or capabilities]**.

Do not hide uncertainty. Use conditional language for hypotheses.

## 4. Bottom-up narrative

Use a chain such as:

> We provide **[features]** to enable **[experience]**. That experience is expected to produce **[benefits]**, contributing to **[purpose]**.

State whether evidence supports the chain or it remains a strategic hypothesis.

## 5. Traceability matrix

| Purpose | Benefit | Experience | Feature or capability | Link mechanism | Evidence state | Confidence |
|---|---|---|---|---|---|---|
| | | | | | | |

Create one row per meaningful causal path. Do not repeat identical rows merely to create visual completeness.

## 6. Integrity audit

### Orphans

Features or activities without a credible upward path.

### Gaps

Benefits or experiences without enough enabling support.

### Weak links

Connections that are vague, untested, indirect, or dependent on hidden assumptions.

### Contradictions

Elements that optimize against one another or serve incompatible purposes, beneficiaries, or horizons.

### Simplification opportunities

Places where a smaller or different capability could create the same value.

## 8. Executive version

For a brief audience, reduce the work to:

1. The purpose and beneficiary.
2. The two or three decisive benefits.
3. The experience principle that produces them.
4. The smallest enabling capability set.
5. The largest gap or risk.
6. The decision required now.

Use answer-first grouping. Avoid presenting the framework mechanics unless they help the audience decide.
