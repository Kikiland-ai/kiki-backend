# ClassPulseBar

For teachers: one concept's class split into mastered, language gap and concept gap, with the numbers in words beside the bar.

**Consumer provides:** `label`, `mastered`, `language`, `concept` (percentages), optional `students`, `hidden` (true when fewer than 10 students tried it).

- Do: show class totals only.
- Don't: link to individual students' answers unless the student shared them.
