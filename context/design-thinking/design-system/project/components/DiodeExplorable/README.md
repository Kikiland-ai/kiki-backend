# DiodeExplorable

The worked-example interactive: drag the voltage across a silicon diode and watch current flow in the circuit and the point move along the V-I curve.

**Consumer provides:** optional `defaultVoltage` (volts, -2 to 1), `id` for the slider. The model is an ideal-ish silicon diode with the knee near 0.7 V; Kiki points when the voltage is near the knee.

This is the template for every explorable: one schematic, one slider, one live plot, one Kiki line. Build a new one per concept with the same parts.
