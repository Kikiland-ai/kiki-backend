# FaultCard

The debug challenge card: the fault type, the visible symptom, Kiki's "why" questions one at a time, and the fixed state.

**Consumer provides:** `type` (one of the seven fault types: Flipped, Wrong value, Missing piece, Wrong connection, Wrong tool setting, Wrong measurement, Wrong assumption), `symptom`, `questions` (three, open to specific), optional `fixed`, `fixedMessage`, `onFixed`.

- Do: choose the fault card from the student's weakest misconception.
- Don't: give the fix before the third question.
