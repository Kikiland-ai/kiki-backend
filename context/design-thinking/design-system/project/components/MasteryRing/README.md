# MasteryRing

A four-segment ring showing mastery of one concept: Concept (blue), Words (red), English (yellow), Lab (green), clockwise from the top.

**Consumer provides:** `values` (`{concept, words, english, lab}`, each 0 to 1, from rubric evidence only), optional `size` (44 on the map, 96 in the lesson header, 160+ on the receipt), `locked` (dimension keys drawn dashed, such as `["lab"]` before the lab), `flicker` (time to revise), `label`, and `children` for the centre.

- Do: fill segments only from real evidence; a full ring spins once and glows.
- Don't: animate a segment to make someone feel good. Never show a ring without its four colours in this order.
