# SourceTag

A chip on a lesson card naming where its content came from, such as "From your notes, page 7"; tapping shows the snippet and any conflict with the textbook.

**Consumer provides:** `label`, `source` (file name), `snippet`, optional `conflict` (one sentence telling the student which value to use in the exam).

- Do: show the student's own material first; it is the first source of truth.
