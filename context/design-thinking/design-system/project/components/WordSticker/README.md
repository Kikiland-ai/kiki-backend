# WordSticker

A collectible card for one technical term that flips to show the Odia meaning and an example sentence.

**Consumer provides:** `term`, optional `entry` (`{odia, example}`), `state` (`new`: dashed edge, `collected`, `owned`: solid red once used correctly in English twice).

- Do: reuse stickers as insertable chips in English answers.
- Don't: show more than three new stickers in one Collect beat.
