# Prepared frontend examples

Request shapes are live local FastAPI contracts; placeholder IDs/revisions must be replaced with current server values. `mixed-language.create.request.json` uses the existing prepared VCO source, not a URL fetching/content-catalog endpoint.

Files with `synthetic.response` in their names were generated through the unified app with an explicit fixture text generator and an empty synthetic lab. They are examples of returned structure, not user evidence or provider quality. Their random IDs/timestamps are illustrative; never copy them into a live check. Response mode `injected_test_adapter` and review-pending labels remain visible. Audio was disabled in these response examples; the acceptance suite checks separate synthetic WAV readiness/failure/cancellation.

The actual user-tested cloud Site still uses lab-demo/v1 on Worker/D1; these lab-python/v1 examples are for the consolidated Python deployment, which is pending.
